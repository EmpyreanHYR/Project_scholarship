# 优秀学生奖学金加分项目评审软件

## 🌟 特性概览

- 🔐 **安全可靠**：多用户管理，账户安全机制
- 📊 **批量处理**：一次导入多个学生，支持大规模评审
- 🔄 **智能切换**：无缝切换学生数据，自动保存进度
- 🎯 **精准评审**：自定义加分规则，支持多种项目类型
- 🖼️ **材料预览**：内置图片和PDF预览功能
- 📤 **批量导出**：一键导出所有结果，支持多种格式
- 🎨 **友好界面**：响应式设计，支持主题切换
- 💾 **数据库支持**：可选的数据库集成，历史记录查询与导出（v3.0新增）

## 项目简介

本项目是一个基于Python Tkinter开发的优秀学生奖学金加分项目评审软件，主要用于高校学生奖学金加分项目的评审工作。软件提供了用户管理、Excel数据导入、批量导入、支撑材料预览、评审决策、批量导出等完整的评审流程功能，特别针对大规模多学生评审场景进行了优化。

## 主要功能

### 🔐 用户管理系统

- **用户注册与登录**：支持多用户注册和安全登录
- **账户安全机制**：连续失败3次自动锁定账户，支持管理员解锁
- **权限控制**：需要登录后才能导入Excel文件进行评审

### 📊 数据管理

- **Excel文件导入**：支持导入包含学生信息和奖项数据的Excel文件
- **批量导入功能**：🆕 支持一次性导入多个学生的Excel文件进行批量评审
- **补充导入功能**：🆕 支持在已有数据基础上追加导入新的学生Excel文件，无需重新选择所有文件
- **学生切换管理**：通过下拉菜单便捷切换不同学生的评审数据
- **学生信息展示**：自动显示学院、姓名、年级、班级、学号等基本信息
- **奖项信息管理**：以表格形式展示所有奖项的详细信息
- **数据持久化**：智能保存每个学生的评审进度，切换学生时自动保存当前进度

### 🖼️ 支撑材料预览

- **图片预览**：支持JPG、JPEG、PNG格式的图片直接预览
- **PDF文档**：支持打开PDF格式的支撑材料
- **智能匹配**：根据奖项名称自动匹配对应的支撑材料文件

### ⚙️ 自定义加分规则（V2.0新增功能）

- **导入加分详情**：支持从Excel文件导入自定义的项目类型、奖项级别和加分规则
- **动态规则切换**：可以在默认规则和自定义规则之间切换
- **重置功能**：一键恢复到系统默认的加分规则
- **灵活配置**：支持任意项目类型和奖项级别的自定义配置
- **自定义分数上限**：支持在加分详情Excel第四列为每类项目设置统计分数上限，无则默认6分

### 📝 评审功能

- **项目分类**：支持竞赛类、科研创新类、外语类等多种项目类型
- **等级评定**：根据项目类型动态显示相应的奖项级别选项
- **认定决策**：支持"认定"和"不予认定"两种评审结果
- **备注管理**：不予认定时必须填写详细备注说明
- **自动计分**：根据项目类型和等级自动计算加分值

### 📤 结果导出

- **单学生评审结果导出**：导出包含完整评审信息的Excel文件
- **批量评审结果导出**：🆕 一键导出所有学生的详细评审结果到指定目录
- **单学生统计结果导出**：按项目类型统计总分，若自定义加分规则含上限则按上限截断，否则默认每类最高6分
- **批量统计结果导出**：🆕 批量导出所有学生的统计结果汇总，自动按自定义上限或默认6分截断
- **智能文件命名**：自动生成规范的文件名格式（学院_姓名_年级_班级_学号）
- **导出进度检查**：自动检测未完成评审的学生并提供提醒
- **多格式支持**：支持详细评审数据和统计汇总两种导出格式
- **全部学生评审结果总表**：批量评审结果导出时，自动生成“全部学生评审结果总表.xlsx”，包含所有学生所有奖项的完整明细，便于统一汇总和查阅。

### 🎨 界面与体验

- **响应式布局**：自适应屏幕大小，支持全屏显示
- **主题切换**：支持浅色和深色两种界面主题
- **操作便捷**：评审完成后自动跳转到下一个未评审项目
- **进度追踪**：实时显示评审进度和完成状态

## 批量处理功能详解

### 🚀 功能优势

批量处理功能是V2.0版本的核心亮点，专为大规模学生评审场景设计：

- **高效评审**：支持同时导入几十甚至上百个学生的数据文件
- **进度保存**：每个学生的评审进度独立保存，随时切换不会丢失数据
- **便捷切换**：通过下拉菜单快速在不同学生之间切换
- **批量导出**：一键导出所有学生的结果，无需逐个操作
- **智能检测**：自动检测未完成评审的学生并提供提醒

### 📋 适用场景

- **学院级评审**：一个学院几十个学生的奖学金评审
- **班级批量处理**：一个班级所有学生的加分项目统一评审
- **多评审员协作**：不同评审员可以分别处理不同学生的数据
- **大型评审活动**：校级、院级大规模奖学金评审活动
- **补充导入典型场景**：
  - 先导入部分学生，后续发现有遗漏或新增学生时，直接点击“补充导入Excel文件”即可追加，无需重新选择全部文件
  - 单文件评审后发现需批量处理，点击“补充导入”自动切换为批量模式

### 💡 使用建议

1. **文件组织**：建议将所有学生的Excel文件放在同一目录下
2. **命名规范**：使用统一的文件命名格式便于管理
3. **分批处理**：对于超大规模数据，建议分批导入处理
4. **及时保存**：系统会自动保存进度，但建议定期手动导出备份

## 📦 数据库集成功能（V3.0）

### 概述

V3.0版本新增了**可选的数据库集成功能**，完全不影响原有功能的使用。数据库功能默认禁用，需手动配置启用。

### 核心特性

- ✅ **完全可选**：数据库功能默认禁用，不影响原有功能
- ✅ **自动记录**：Excel导入和评审结果自动保存到数据库
- ✅ **历史查询**：支持按批次、学生、项目类型、评审人等多维度查询
- ✅ **批次导出**：支持导出完整批次数据（多Sheet Excel）
- ✅ **审计日志**：完整记录所有操作，便于追溯

### 快速启用

**1. 安装数据库依赖**

```bash
# PostgreSQL
pip install sqlalchemy psycopg2-binary

# MySQL  
pip install sqlalchemy pymysql
```

**2. 配置数据库**

```bash
cp db_config.example.json db_config.json
```

编辑 `db_config.json`：

```json
{
    "enabled": true,
    "db_type": "postgresql",
    "host": "localhost",
    "port": 5432,
    "database": "scholarship_db",
    "username": "your_username",
    "password": "your_password"
}
```

**3. 初始化数据库**

```bash
python3 -c "from database.migrate import init_database_schema; init_database_schema()"
```

**4. 验证配置**

```bash
python3 verify_system.py
```

### 新增功能

启用数据库后，主界面会显示**"历史记录"**按钮，支持：

- **批次查询**：按学年、学期、状态筛选评审批次
- **学生查询**：按学号、姓名、专业、年级查询
- **申请查询**：按项目类型、分数范围、时间查询
- **评审查询**：按评审人、状态、时间查询
- **批次导出**：导出完整批次（包含汇总、学生列表、评审结果、申请详情4个Sheet）
- **结果导出**：导出查询结果到Excel

### 数据库模型

系统使用5个表存储数据：

- `review_batches` - 评审批次
- `students` - 学生信息
- `applications` - 申请记录
- `reviews` - 评审结果
- `audit_logs` - 审计日志

### 禁用数据库

如不需要数据库功能，在 `db_config.json` 中设置：

```json
{
    "enabled": false
}
```

程序将正常运行，所有原有功能不受影响。

### 使用流程

1. **用户注册/登录**：首次使用需要注册账户，之后登录系统
2. **数据导入**：

   - **单学生模式**：点击"请选择Excel文件"导入单个学生的奖项数据
   - **批量模式**：点击"批量导入Excel文件"一次性导入多个学生的Excel文件
   - **补充导入**：如需追加学生文件，点击"补充导入Excel文件"，可在单文件模式下自动转为批量模式，也可在批量模式下继续追加新学生文件，无需重新选择全部文件
3. **学生切换**（批量模式）：

   - 使用"学生选择"下拉菜单切换不同学生的评审数据
   - 系统自动保存每个学生的评审进度
4. **配置加分规则**（可选）：

   - 点击"导入加分详情"按钮导入自定义加分规则Excel文件
   - 或使用系统默认的加分规则
5. **开始评审**：

   - 在表格中选择要评审的奖项
   - 在右侧评审面板中选择项目类型和奖项级别
   - 选择认定情况（认定/不予认定）
   - 如选择不予认定，必须填写备注
   - 点击"确定"完成单项评审
6. **导出结果**：

   - **单学生导出**：
     - 点击"评审结果导出Excel"导出详细评审结果
     - 点击"统计结果导出Excel"导出按类别统计的加分汇总
   - **批量导出**：
     - 点击"批量评审结果导出"导出所有学生的详细评审结果
     - 点击"批量统计结果导出"导出所有学生的统计汇总

## 文件格式说明

### 学生数据Excel格式

**单学生文件**和**批量导入文件**均需包含以下列：

- 学院
- 姓名
- 年级
- 班级
- 学号
- 所获奖项名称
- 获奖时间
- 奖项等级

**批量导入说明**：

- 支持同时选择多个Excel文件进行批量导入
- 每个Excel文件应包含一个学生的完整奖项数据
- 文件名建议使用规范格式：学院_姓名_年级_班级_学号.xlsx
- 系统会自动识别每个文件中的学生信息并建立索引

### 加分详情Excel格式（自定义规则）

必须包含前三列，支持可选第四列：

- 第一列：项目类型（如：科研、创新、创业等）
- 第二列：奖项级别（如：一等、二等、三等等）
- 第三列：加分值（数字）
- 第四列（可选）：加分上限（数字，若填写则该项目类型统计时按此上限截断，否则默认6分）

### 支撑材料文件命名

支撑材料文件名应与奖项名称对应：

- 图片格式：奖项名称.jpg/.jpeg/.png
- PDF格式：奖项名称.pdf

## 默认加分规则

### 竞赛类加分

- 国家级：一等奖(6分)、二等奖(4分)、三等奖(3分)
- 省级：一等奖(5分)、二等奖(3分)、三等奖(2分)
- 市级：一等奖(3分)、二等奖(2分)、三等奖(1分)
- 校级：一等奖(2分)、二等奖(1分)、三等奖(0.5分)
- 院级：一等奖(1分)、二等奖(0.5分)、三等奖(0.3分)

### 科研创新类加分

- 国家级立项：主持人(6分)、成员(4分)
- 省级重点立项：主持人(5分)、成员(3分)
- 省级一般立项：主持人(3分)、成员(2分)
- 校级立项：主持人(2分)、成员(1分)
- 论文发表：SCI一作(6分)、核心期刊一作(3分)、普通期刊一作(2分)
- 专利申请：发明专利一作(6分)、实用新型一作(2分)、外观专利一作(2分)

### 外语类加分

- CET4(1分)、CET6(2分)
- TEM4(1分)、TEM8(2分)
- 雅思、托福、GRE、GMAT等(2分)
