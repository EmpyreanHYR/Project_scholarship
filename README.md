# 优秀学生奖学金加分项目评审软件

## 项目简介

本项目是一个基于Python Tkinter开发的优秀学生奖学金加分项目评审软件，主要用于高校学生奖学金加分项目的评审工作。软件提供了用户管理、Excel数据导入、支撑材料预览、评审决策、结果导出等完整的评审流程功能。

## 主要功能

### 🔐 用户管理系统

- **用户注册与登录**：支持多用户注册和安全登录
- **账户安全机制**：连续失败3次自动锁定账户，支持管理员解锁
- **权限控制**：需要登录后才能导入Excel文件进行评审

### 📊 数据管理

- **Excel文件导入**：支持导入包含学生信息和奖项数据的Excel文件
- **学生信息展示**：自动显示学院、姓名、年级、班级、学号等基本信息
- **奖项信息管理**：以表格形式展示所有奖项的详细信息

### 🖼️ 支撑材料预览

- **图片预览**：支持JPG、JPEG、PNG格式的图片直接预览
- **PDF文档**：支持打开PDF格式的支撑材料
- **智能匹配**：根据奖项名称自动匹配对应的支撑材料文件

### ⚙️ 自定义加分规则（V3.0新增功能）

- **导入加分详情**：支持从Excel文件导入自定义的项目类型、奖项级别和加分规则
- **动态规则切换**：可以在默认规则和自定义规则之间切换
- **重置功能**：一键恢复到系统默认的加分规则
- **灵活配置**：支持任意项目类型和奖项级别的自定义配置

### 📝 评审功能

- **项目分类**：支持竞赛类、科研创新类、外语类等多种项目类型
- **等级评定**：根据项目类型动态显示相应的奖项级别选项
- **认定决策**：支持"认定"和"不予认定"两种评审结果
- **备注管理**：不予认定时必须填写详细备注说明
- **自动计分**：根据项目类型和等级自动计算加分值

### 📤 结果导出

- **评审结果导出**：导出包含完整评审信息的Excel文件
- **统计结果导出**：按项目类型统计总分，自动限制每类最高6分
- **文件命名**：自动生成规范的文件名格式

### 🎨 界面与体验

- **响应式布局**：自适应屏幕大小，支持全屏显示
- **主题切换**：支持浅色和深色两种界面主题
- **操作便捷**：评审完成后自动跳转到下一个未评审项目
- **进度追踪**：实时显示评审进度和完成状态

## 系统要求

- Python 3.8+
- Windows 操作系统
- 所需Python库：
  - tkinter（GUI界面）
  - pandas（数据处理）
  - openpyxl（Excel文件操作）
  - Pillow（图像处理）
  - json（用户数据管理）

## 安装与使用

### 环境配置

```bash
# 安装依赖包
pip install pandas openpyxl Pillow
```

### 运行软件

```bash
# 运行主程序
python jxj_main3.py
```

### 使用流程

1. **用户注册/登录**：首次使用需要注册账户，之后登录系统
2. **导入数据**：点击"请选择Excel文件"导入学生奖项数据
3. **配置加分规则**（可选）：
   - 点击"导入加分详情"按钮导入自定义加分规则Excel文件
   - 或使用系统默认的加分规则
4. **开始评审**：
   - 在表格中选择要评审的奖项
   - 在右侧评审面板中选择项目类型和奖项级别
   - 选择认定情况（认定/不予认定）
   - 如选择不予认定，必须填写备注
   - 点击"确定"完成单项评审
5. **导出结果**：
   - 点击"评审结果导出Excel"导出详细评审结果
   - 点击"统计结果导出Excel"导出按类别统计的加分汇总

## 文件格式说明

### 学生数据Excel格式

必须包含以下列：

- 学院
- 姓名
- 年级
- 班级
- 学号
- 所获奖项名称
- 获奖时间
- 奖项等级

### 加分详情Excel格式（自定义规则）

必须包含三列：

- 第一列：项目类型（如：科研、创新、创业等）
- 第二列：奖项级别（如：一等、二等、三等等）
- 第三列：加分值（数字）

### 支撑材料文件命名

支撑材料文件名应与奖项名称对应：

- 图片格式：奖项名称.jpg/.jpeg/.png
- PDF格式：奖项名称.pdf

## 默认加分规则

### 竞赛类加分

- 国家级：一等奖(6分)、二等奖(4分)、三等奖(3分)
- 省级：一等奖(5分)、二等奖(3分)、三等奖(2分)
- 市级：一等奖(3分)、二等奖(2分)、三等奖(1分)
- 校级：一等奖(2分)、二等奖(1分)、三等奖(0.5分)
- 院级：一等奖(1分)、二等奖(0.5分)、三等奖(0.3分)

### 科研创新类加分

- 国家级立项：主持人(6分)、成员(4分)
- 省级重点立项：主持人(5分)、成员(3分)
- 省级一般立项：主持人(3分)、成员(2分)
- 校级立项：主持人(2分)、成员(1分)
- 论文发表：SCI一作(6分)、核心期刊一作(3分)、普通期刊一作(2分)
- 专利申请：发明专利一作(6分)、实用新型一作(2分)、外观专利一作(2分)

### 外语类加分

- CET4(1分)、CET6(2分)
- TEM4(1分)、TEM8(2分)
- 雅思、托福、GRE、GMAT等(2分)
