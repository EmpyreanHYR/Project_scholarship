- 🔐 **安全可靠**：多用户管理，角色权限控制，账户安全机制

- 📊 **数据可视化**：统计图表面板，分数分布、排名对比一目了然
- 🎨 **友好界面**：响应式设计，支持主题切换
- 💾 **数据库支持**：可选的数据库集成，历史记录查询与导出（v3.0新增）
- 💾 **数据备份恢复**：🆕 自动/手动备份，支持数据恢复（v3.1新增）
- ⏱️ **自动保存**：🆕 定时自动保存评审进度，崩溃恢复（v3.1新增）

- 📥 **多格式导入**：🆕 支持 CSV、JSON 等多种格式导入（v3.1新增）
- 🔍 **结果对比**：🆕 批次对比分析，评审趋势分析（v3.1新增）

## 项目简介

本项目是一个基于Python Tkinter开发的优秀学生奖学金加分项目评审软件，主要用于高校学生奖学金加分项目的评审工作。软件提供了用户管理、Excel数据导入、批量导入、支撑材料预览、评审决策、批量导出等完整的评审流程功能，特别针对大规模多学生评审场景进行了优化。

## 主要功能

### 🔐 用户管理系统

- **用户注册与登录**：支持多用户注册和安全登录
- **角色权限控制**：🆕 支持管理员（admin）和评审员（reviewer）两种角色，管理员可管理所有用户
- **管理员面板**：🆕 提供用户管理界面，支持解锁账户、切换角色、删除用户
- **账户安全机制**：连续失败3次自动锁定账户，管理员可解锁
- **权限控制**：需要登录后才能导入Excel文件进行评审
- **自动格式迁移**：🆕 旧版本用户数据自动升级，无需手动迁移

### 📊 数据管理

- **Excel文件导入**：支持导入包含学生信息和奖项数据的Excel文件
- **智能数据校验**：🆕 自动校验必需列、跳过空行、规范化日期格式（支持多种格式），清除无效加分值
- **校验摘要提示**：🆕 导入后展示详细的校验结果（警告项/错误项），帮助快速定位数据问题
- **批量导入功能**：🆕 支持一次性导入多个学生的Excel文件进行批量评审
- **补充导入功能**：🆕 支持在已有数据基础上追加导入新的学生Excel文件，无需重新选择所有文件
- **学生切换管理**：通过下拉菜单便捷切换不同学生的评审数据
- **学生信息展示**：自动显示学院、姓名、年级、班级、学号等基本信息
- **奖项信息管理**：以表格形式展示所有奖项的详细信息
- **数据持久化**：智能保存每个学生的评审进度，切换学生时自动保存当前进度

### 🖼️ 支撑材料预览

- **图片预览**：支持JPG、JPEG、PNG格式的图片直接预览
- **PDF文档**：支持打开PDF格式的支撑材料
- **智能匹配**：根据奖项名称自动匹配对应的支撑材料文件

### ⚙️ 自定义加分规则（V2.0新增功能）

- **导入加分详情**：支持从Excel文件导入自定义的项目类型、奖项级别和加分规则
- **动态规则切换**：可以在默认规则和自定义规则之间切换
- **重置功能**：一键恢复到系统默认的加分规则
- **灵活配置**：支持任意项目类型和奖项级别的自定义配置
- **自定义分数上限**：支持在加分详情Excel第四列为每类项目设置统计分数上限，无则默认6分

### 📝 评审功能

- **项目分类**：支持竞赛类、科研创新类、外语类等多种项目类型
- **等级评定**：根据项目类型动态显示相应的奖项级别选项
- **认定决策**：支持"认定"和"不予认定"两种评审结果
- **备注管理**：不予认定时必须填写详细备注说明
- **自动计分**：根据项目类型和等级自动计算加分值
- **撤销与重做**：🆕 支持 Ctrl+Z 撤销最近评审操作，Ctrl+Y 重做，评审更从容
- **自动跳转**：评审完成后自动跳转到下一个未评审项目

### 📤 结果导出

- **单学生评审结果导出**：导出包含完整评审信息的Excel文件
- **批量评审结果导出**：🆕 一键导出所有学生的详细评审结果到指定目录
- **单学生统计结果导出**：按项目类型统计总分，若自定义加分规则含上限则按上限截断，否则默认每类最高6分
- **批量统计结果导出**：🆕 批量导出所有学生的统计结果汇总，自动按自定义上限或默认6分截断
- **PDF 评审报告**：🆕 导出 A4 格式的 PDF 个人评审报告，含学生信息、奖项明细表、分类统计
- **PDF 批量汇总**：🆕 导出所有学生的 PDF 汇总排名表，适合打印存档
- **智能文件命名**：自动生成规范的文件名格式（学院_姓名_年级_班级_学号）
- **导出进度检查**：自动检测未完成评审的学生并提供提醒
- **多格式支持**：支持 Excel 和 PDF 两种导出格式
- **全部学生评审结果总表**：批量评审结果导出时，自动生成“全部学生评审结果总表.xlsx”，包含所有学生所有奖项的完整明细，便于统一汇总和查阅。

### 🎨 界面与体验

- **响应式布局**：自适应屏幕大小，支持全屏显示
- **主题切换**：支持浅色和深色两种界面主题
- **操作便捷**：评审完成后自动跳转到下一个未评审项目
- **进度追踪**：实时显示评审进度和完成状态
- **快捷键支持**：🆕 Ctrl+Z 撤销、Ctrl+Y 重做，提升评审效率

### 📊 数据可视化（V3.0新增）

- **统计面板**：🆕 一键打开数据可视化窗口，四张图表全景展示评审数据
- **总分分布直方图**：直观查看学生加分总分的分布情况
- **类别加分饼图**：各类加分项目占比一目了然
- **评审进度环形图**：已完成/未完成项目数量对比
- **学生排名柱状图**：批量模式下按总分排名，单学生模式下按类别分解
- **图表工具栏**：支持缩放、平移、保存图表为图片

## 批量处理功能详解

### 🚀 功能优势

批量处理功能是V2.0版本的核心亮点，专为大规模学生评审场景设计：

- **高效评审**：支持同时导入几十甚至上百个学生的数据文件
- **进度保存**：每个学生的评审进度独立保存，随时切换不会丢失数据
- **便捷切换**：通过下拉菜单快速在不同学生之间切换
- **批量导出**：一键导出所有学生的结果，无需逐个操作
- **智能检测**：自动检测未完成评审的学生并提供提醒

### 📋 适用场景

- **学院级评审**：一个学院几十个学生的奖学金评审
- **班级批量处理**：一个班级所有学生的加分项目统一评审
- **多评审员协作**：不同评审员可以分别处理不同学生的数据
- **大型评审活动**：校级、院级大规模奖学金评审活动
- **补充导入典型场景**：
  - 先导入部分学生，后续发现有遗漏或新增学生时，直接点击“补充导入Excel文件”即可追加，无需重新选择全部文件
  - 单文件评审后发现需批量处理，点击“补充导入”自动切换为批量模式

### 💡 使用建议

1. **文件组织**：建议将所有学生的Excel文件放在同一目录下
2. **命名规范**：使用统一的文件命名格式便于管理
3. **分批处理**：对于超大规模数据，建议分批导入处理
4. **及时保存**：系统会自动保存进度，但建议定期手动导出备份

## 📦 SQLite 数据库集成功能（V3.0）

### 概述

V3.0版本新增了**可选的 SQLite 数据库集成功能**，完全不影响原有功能的使用。数据库功能默认禁用，需手动配置启用。

SQLite 是 Python 内置的数据库，无需安装额外数据库服务，数据自动存储在 `data/scholarship.db`。

### 核心特性

- ✅ **开箱即用**：SQLite 是 Python 内置的，无需安装额外数据库服务
- ✅ **完全可选**：数据库功能默认禁用，不影响原有功能
- ✅ **自动记录**：Excel导入和评审结果自动保存到数据库
- ✅ **历史查询**：支持按批次、学生、项目类型、评审人等多维度查询
- ✅ **批次导出**：支持导出完整批次数据（多Sheet Excel）
- ✅ **审计日志**：完整记录所有操作，便于追溯

### 快速启用

**1. 安装依赖**

```bash
pip install sqlalchemy
```

**2. 配置数据库**

编辑项目根目录下的 `db_config.json`：

```json
{
    "enabled": true,
    "db_type": "sqlite",
    "database": "data/scholarship.db",
    "echo": false
}
```

**3. 初始化数据库**

```bash
python -c "from database import init_database_schema; init_database_schema()"
```

**4. 启动主程序**

```bash
python jxj_main3.py
```

启动后若数据库启用成功，主界面会出现"历史记录"入口，可查询并导出历史批次。

### 新增功能

启用数据库后，主界面会显示**"历史记录"**按钮，支持：

- **批次查询**：按学年、学期、状态筛选评审批次
- **学生查询**：按学号、姓名、专业、年级查询
- **申请查询**：按项目类型、分数范围、时间查询
- **评审查询**：按评审人、状态、时间查询
- **批次导出**：导出完整批次（包含汇总、学生列表、评审结果、申请详情4个Sheet）
- **结果导出**：导出查询结果到Excel

### 数据库模型

系统使用5个表存储数据：

- `review_batches` - 评审批次
- `students` - 学生信息
- `applications` - 申请记录
- `reviews` - 评审结果
- `audit_logs` - 审计日志

### 禁用数据库

如不需要数据库功能，在 `db_config.json` 中设置：

```json
{
    "enabled": false
}
```

程序将正常运行，所有原有功能不受影响。

## 🆕 V3.1 新增功能模块

### 数据备份与恢复 (`backup_manager.py`)

**核心功能：**
- **自动备份**：每次导入数据或完成评审时自动备份
- **手动备份**：用户可随时手动创建备份，支持添加描述
- **恢复数据**：从备份文件恢复评审数据
- **备份管理**：查看、删除、导出备份文件
- **自动清理**：保留最新的 N 个备份，自动删除旧备份

**使用方式：**
```python
from backup_manager import BackupManager, BackupDialog

# 创建备份管理器
backup_mgr = BackupManager(backup_dir="backups", max_backups=10)

# 创建备份
result = backup_mgr.create_backup(data, description="评审数据备份")

# 恢复备份
data = backup_mgr.restore_backup(backup_file)
```

### 自动保存 (`auto_save.py`)

**核心功能：**
- **定时自动保存**：可配置间隔（默认 5 分钟）
- **数据变化检测**：避免重复保存相同数据
- **崩溃恢复**：程序崩溃后自动检测并恢复数据
- **状态栏显示**：实时显示保存状态和次数

**使用方式：**
```python
from auto_save import AutoSaveManager, AutoSaveStatusBar

# 创建自动保存管理器
auto_save = AutoSaveManager(save_dir="autosave", save_interval=300)

# 启动自动保存
auto_save.start(save_callback=get_data_func)

# 立即保存
auto_save.save_now(description="手动保存")
```

### 评审进度追踪 (`progress_tracker.py`)

**核心功能：**
- **可视化仪表盘**：概览卡片、进度条、学生进度表格
- **多维度统计**：总学生数、总奖项数、已评审、待评审、完成率、认定率
- **进度预测**：根据评审速度预估完成时间
- **每日进度**：跟踪每日评审数量
- **评审历史**：记录所有评审操作
- **进度报告**：生成文本格式的进度报告

**使用方式：**
```python
from progress_tracker import ReviewProgressTracker, ProgressDashboard

# 创建进度追踪器
tracker = ReviewProgressTracker()

# 初始化
tracker.initialize(students_data)

# 记录评审
tracker.record_review(student_id, award_name, decision, reviewer)

# 获取进度摘要
summary = tracker.get_progress_summary()

# 打开仪表盘
ProgressDashboard(root, tracker)
```

### 增强数据导入 (`data_importer.py`)

**核心功能：**
- **多格式支持**：Excel (.xlsx/.xls)、CSV、JSON、Tab 分隔文本
- **自动检测**：自动检测文件编码和分隔符
- **数据验证**：检查必需列、空值、重复行
- **数据清洗**：删除空行、重复行
- **批量导入**：支持一次导入多个文件或整个文件夹

**使用方式：**
```python
from data_importer import DataImporter, EnhancedImportDialog

# 创建数据导入器
importer = DataImporter()

# 导入文件
df = importer.import_file("data.csv")

# 验证数据
is_valid, errors, warnings = importer.validate_data(df, required_columns=['姓名', '学号'])

# 打开导入对话框
EnhancedImportDialog(root, importer, callback=on_import_complete)
```

### 评审结果对比分析 (`review_comparator.py`)

**核心功能：**
- **批次对比**：对比不同批次的评审结果
- **学生历史**：查看单个学生的历史评审记录
- **分数变化**：分析分数增加/减少/不变的情况
- **趋势分析**：分析评审趋势（上升、下降、稳定）
- **统计报表**：生成批次统计信息

**使用方式：**
```python
from review_comparator import ReviewComparator, ComparisonDialog

# 创建对比器
comparator = ReviewComparator()

# 添加批次
comparator.add_batch('2024春季', batch1_data, '2024年春季评审')
comparator.add_batch('2024秋季', batch2_data, '2024年秋季评审')

# 对比批次
comparison = comparator.compare_batches('2024春季', '2024秋季')

# 打开对比对话框
ComparisonDialog(root, comparator)
```

   - **批量导出**：
     - 点击"批量评审结果导出"导出所有学生的详细评审结果
     - 点击"批量统计结果导出"导出所有学生的统计汇总

## 文件格式说明

### 学生数据Excel格式

**单学生文件**和**批量导入文件**均需包含以下列：

- 学院
- 姓名
- 年级
- 班级
- 学号
- 所获奖项名称
- 获奖时间
- 奖项等级

**批量导入说明**：

- 支持同时选择多个Excel文件进行批量导入
- 每个Excel文件应包含一个学生的完整奖项数据
- 文件名建议使用规范格式：学院_姓名_年级_班级_学号.xlsx
- 系统会自动识别每个文件中的学生信息并建立索引

### 加分详情Excel格式（自定义规则）

必须包含前三列，支持可选第四列：

- 第一列：项目类型（如：科研、创新、创业等）
- 第二列：奖项级别（如：一等、二等、三等等）
- 第三列：加分值（数字）
- 第四列（可选）：加分上限（数字，若填写则该项目类型统计时按此上限截断，否则默认6分）

### 支撑材料文件命名

支撑材料文件名应与奖项名称对应：

- 图片格式：奖项名称.jpg/.jpeg/.png
- PDF格式：奖项名称.pdf

## 默认加分规则

### 竞赛类加分

- 国家级：一等奖(6分)、二等奖(4分)、三等奖(3分)
- 省级：一等奖(5分)、二等奖(3分)、三等奖(2分)
- 市级：一等奖(3分)、二等奖(2分)、三等奖(1分)
- 校级：一等奖(2分)、二等奖(1分)、三等奖(0.5分)
- 院级：一等奖(1分)、二等奖(0.5分)、三等奖(0.3分)

### 科研创新类加分

- 国家级立项：主持人(6分)、成员(4分)
- 省级重点立项：主持人(5分)、成员(3分)
- 省级一般立项：主持人(3分)、成员(2分)
- 校级立项：主持人(2分)、成员(1分)
- 论文发表：SCI一作(6分)、核心期刊一作(3分)、普通期刊一作(2分)
- 专利申请：发明专利一作(6分)、实用新型一作(2分)、外观专利一作(2分)

### 外语类加分

- CET4(1分)、CET6(2分)
- TEM4(1分)、TEM8(2分)
- 雅思、托福、GRE、GMAT等(2分)

## 技术特点

- **模块化设计**：采用面向对象编程，代码结构清晰
- **批量处理能力**：支持同时处理多个学生的评审数据，提高工作效率
- **智能数据管理**：自动保存评审进度，支持无缝切换不同学生数据
- **数据安全**：用户数据加密存储，角色权限分离，账户锁定机制
- **操作可逆**：命令模式实现的撤销/重做栈，评审误操作可回退
- **异常处理**：完善的错误处理和用户提示机制
- **扩展性强**：支持自定义加分规则，适应不同学校需求
- **多格式导出**：支持 Excel 和 PDF 双格式导出，满足不同场景
- **可视化分析**：集成 matplotlib，提供丰富的统计图表
- **高性能**：优化的数据结构和算法，支持大规模学生数据处理
- **密码安全**：🆕 使用 PBKDF2-SHA256 哈希存储密码，符合 OWASP 安全标准（v3.1新增）
- **多格式导入**：🆕 支持 Excel、CSV、JSON、Tab 分隔文本等多种格式导入（v3.1新增）
- **数据备份**：🆕 自动/手动备份，支持数据恢复和导出（v3.1新增）
- **进度追踪**：🆕 可视化仪表盘，实时显示评审进度和预测（v3.1新增）
